# homebrew-tap

Homebrew tap for [masseater](https://github.com/masseater)'s tools.

```sh
brew tap masseater/tap
```

## Formulae

### msa

Coding agent CLI with read, bash, edit, write tools and session management.

```sh
brew install masseater/tap/msa
```

### rai

Extensible personal CLI.

```sh
brew install masseater/tap/rai
```

## Casks

### no-mac-music

Stop Music.app from launching on media keys and route them to your player.

```sh
brew install --cask masseater/tap/no-mac-music
```

Formulae and casks here are updated from their source repositories' releases;
edit the source repository, not this tap.
